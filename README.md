# W1 周线买点与10万元模拟仓

[自动运行记录](https://github.com/Bowen389/week1/actions/workflows/w1.yml) · [最新买点及模拟仓](reports/latest.md) · [完整账本](data/state.json)

保留原W1规则，使用腾讯证券公开免费行情。没有券商下单，也不运行历史回测。自部署日起维护独立10万元模拟账本，不追买已经错过的历史买点。

## 每周流程（北京时间）

- 每日17:20运行，20:20补跑，实际开始时间可能受GitHub Actions排队影响。
- 交易日收盘后核验日期及数据；只有当下一交易日跨入新的自然周时，当前周才被判为完整周。
- 在该周最后一个交易日收盘后生成下周首个交易日的开盘买点，提前给出股票名称、代码、周涨幅、52周位置、市值和日期。
- 下一周首个交易日盘后，以该日已公开开盘价模拟记账；不会把盘后价格当成开盘价格。此为理想化开盘成交账本，不代表实际可成交。
- TIME2：买入周为第1周，随后为第2周，买入周周一加14天后的首个交易日开盘退出。比如2026-10-19买入，计划2026-11-02开盘卖出。
- 休市过滤、重复运行去重；买点当天没有成功记账则过期，之后不补买。卖出因停牌或开盘跌停无法模拟执行时，逐交易日顺延。

## W1条件

沪深主板600/601/603/605及000/001/002/003。信号周最后交易日简称非ST或*ST，总市值≤250亿元。使用不复权日线合成为自然周周线，仅分析结束的周。

条件同时满足：C>O；L=O（Decimal严格相等）；H>C；0<H-C≤0.15(C-O)；周涨幅7%至10%（含两端）；截至信号周最近52根周收盘的相对位置≤40%。52周最高最低相等或不足52周不产生信号。停牌而没有日线的日期不创造交易；整周没有K线则没有该周信号。持仓期间忽略新信号。

## 模拟仓配置

- 初始现金100000元，最多10只，单票含费用预算上限10000元；不足100股不买，按代码升序分配。
- 买入及卖出佣金各3bp、最低5元；卖出税费5bp。默认滑点0，未计算券商过户费、分红送股以及实际开盘撮合流动性。
- 开盘触及涨停跳过买入，开盘触及跌停推迟卖出；ST状态改变时采用5%价格边界，新增ST不买。日线不能证明精确开盘成交，这些处理是模拟账本的保守约束。
- 发现持仓除权除息导致昨收口径改变时，暂停账本并报错，需核对公司行动后处理；不会静默伪造盈亏。
- 无止损或新增择时，只有TIME2到期退出。现金、持仓、计划、实际模拟交易和通知状态均写入data/state.json，并自动提交仓库。

## 查看和推送买点

无需配置即可在reports/latest.md、每次Actions摘要及reports/signals-日期.json看到买点。

手机主动推送使用Server酱。在仓库Settings → Secrets and variables → Actions → New repository secret中添加`SERVERCHAN_SENDKEY`，值填自己的Server酱SendKey；已有`SENDKEY`也能识别。密钥只存在Actions Secrets，不写代码和日志。不配置不会阻止扫描或模拟仓运行，只是不发送手机消息。

推送包括每周买点（无信号也明确说明）、模拟买卖与延期退出、引擎数据异常。通知先入账并提交再发送，发送失败可在补跑重试；外部发送成功后状态落盘失败时可能出现重复通知。GitHub自身失败通知取决于个人通知设置。

## 数据与异常处理

腾讯股票列表分页要求总数完全匹配；主板覆盖不少于2500只。快照总市值字段单位为亿元。数据源不收费，不要求登录或行情Token；公开接口仍可能限流或调整格式。

所有合格候选的历史行情下载必须成功，才发布完整周扫描结果；股票历史不足52周按规则排除。接口错误不解释为“没有信号”，失败时保持既有模拟持仓和现金，发布失败报告，晚间自动补跑。周末及非交易日不交易、不扫描新周线。

交易日历为exchange-calendars的XSHG日历，已核对2026年上交所休市安排。当前锁定版本覆盖至2026-12-31；不足未来30天时停止运行并明确提示更新年度日历，不猜测2027年节假日。年底需升级到包含新年度沪市日历的版本并通过日期测试。

## 手动运行与检查

Actions → W1 周线买点与10万元模拟仓 → Run workflow。盘中手动运行会拒绝使用未结束日线，请在北京时间16:00后执行。

本地Python 3.11或以上：

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.run health
python -m src.run run
```

`health`只检查日历、实时行情和历史数据，不改变账本。`run`只运行部署日起的前向模拟，不回填历史收益。工作流所需权限为Contents: write，用于保留账本。

不要删除或重置data/state.json后继续同一个模拟账户，否则等同重新开始。
